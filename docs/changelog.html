Changelog

Every change to nauka, newest first. Releases are git tags (all tags, GitHub releases); the source of this page is CHANGELOG.md.

Unreleased

  • A website (GitHub Pages, https://theyashsawarkar.github.io/nauka/): the README as a home page, the changelog and architecture decision records (docs/adr/), built by scripts/build-site.py like the other Vayu tools' sites; CI checks it's up to date.

v0.1.1(2026-10-27)release ↗

  • The built binary no longer holds a line Vayu's keybinding search took for a broken key description (it scans plugins' bin/ folders).

v0.1.0(2026-10-27)release ↗

  • First release: containers, compose projects, images, volumes, networks and disk use in one screen. A container's details show the volumes and networks it's attached to (Enter jumps to them, Backspace comes back), its logs, stats, environment (secrets hidden), inspect and files.
  • Actions: start/stop, restart, pause, shell, follow logs, remove; compose up/down/restart/build/pull/logs/edit; image run/pull/remove; volume browse/create/remove; network connect/disconnect/create/remove; prune any kind, or everything. Deleting asks first and says what goes.
  • tmux plugin: prefix D opens it in a popup.
